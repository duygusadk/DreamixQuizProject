# 🎯 Quiz Management System

**Quiz Management System** е RESTful приложение, изградено със **Spring Boot**, което позволява управление на потребители, тестове (quizzes) и въпроси.  
Системата поддържа CRUD операции и изчисляване на резултатите на потребителите според техните отговори.

---

## 🚀 Основни функционалности

✅ Управление на **потребители (Users)**  
- Създаване, редактиране, изтриване и преглед на всички потребители.

✅ Управление на **тестове (Quizzes)**  
- Добавяне на тест към потребител.  
- Редактиране, изтриване и извличане на тестове.  
- Изчисляване на резултат според въведените отговори.

✅ Управление на **въпроси (Questions)**  
- CRUD операции за въпроси, асоциирани към конкретен тест.  
- Връщане на въпроси без верните отговори (за използване от клиент).

---

## 🧩 Архитектура

Проектът следва класическата **3-слойна архитектура**:

- **Controller**: Обработва HTTP заявки и връща отговори (JSON).
- **Service**: Съдържа бизнес логиката.
- **Repository**: Комуникира с базата данни чрез JPA.
- **Entity**: Моделира базовите обекти (User, Quiz, Question, UserResponse).
